# 🔒 Telegram-бот платної підписки на закритий канал

Бот продає доступ до приватного Telegram-каналу: приймає оплату, автоматично видає одноразове посилання, нагадує про закінчення підписки та сам видаляє з каналу тих, у кого вона закінчилась.

**Стек:** Python 3, aiogram 3, SQLite, asyncio

## Можливості

**Для клієнта**
- тарифи на 1 / 3 / 12 місяців;
- оплата через **Telegram Stars** (вбудована оплата Telegram);
- оплата **переказом на картку** з надсиланням фото або PDF квитанції;
- після оплати — **одноразове посилання** в канал (1 людина, діє 24 години);
- розділ «Моя підписка»: дата закінчення, залишок днів, нове посилання, продовження.

**Автоматично**
- нагадування за 3 дні та за 1 день до закінчення підписки;
- видалення з каналу після закінчення підписки;
- продовження додає дні до поточної дати закінчення, а не «згоряє».

**Для адміністратора** (`/admin`)
- перевірка оплат за квитанціями: «Підтвердити / Відхилити» в один клік;
- статистика: користувачі, активні підписки, дохід за місяць (грн і ⭐);
- ручна видача підписки за Telegram ID;
- розсилка будь-якого повідомлення всім користувачам;
- `/refund N` — повернення Stars за оплату №N із закриттям доступу.

## Структура проєкту

```
bot.py            — запуск бота і фонової перевірки підписок
config.py         — налаштування та тарифи
db.py             — робота з базою SQLite
keyboards.py      — кнопки
services.py       — видача та відкликання доступу до каналу
scheduler.py      — нагадування і видалення з каналу
handlers/
    user.py       — меню, тарифи, оплата на картку
    payments.py   — оплата Telegram Stars
    admin.py      — панель адміністратора
    channel.py    — визначення ID каналу
```

## Запуск

1. Створіть бота в [@BotFather](https://t.me/BotFather) та приватний канал.
2. Додайте бота адміністратором каналу з правами **«Додавання учасників»** і **«Блокування користувачів»**.
3. Встановіть залежності:
   ```
   pip install -r requirements.txt
   ```
4. Створіть файл `.env` за зразком `.env.example`.
5. Запустіть:
   ```
   python bot.py
   ```
   Якщо `CHANNEL_ID` ще не відомий — запустіть бота, видаліть його з адмінів каналу і додайте знову: бот сам надішле адміну ID каналу.

Тарифи, ціни та опис каналу змінюються у файлі `config.py`.
